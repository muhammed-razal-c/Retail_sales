# Retail Sales Report

A Power BI portfolio project that uses a cleaned online-retail data model to explore sales records and item quantities.

## Open the report

Download [retail_sales_store.pbix](retail_sales_store.pbix) and open it in Power BI Desktop. The report includes a single page and an embedded data model with a table named `Online_Retail_Cleaned_1`.

The report page includes summary cards based on the country and quantity fields. The country card counts records with a country value. The quantity calculation sums item quantities. To see where the numbers come from, select a card and review its fields in the Visualizations pane.
